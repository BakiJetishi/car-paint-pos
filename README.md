🚗 Paint Shop POS — Full-Stack Point of Sale System

This is a modern, full-stack POS (Point of Sale) application built for a car paint shop. It supports product management, customer orders, stock tracking, and messaging features. The app is designed with performance, usability, and clean UI in mind.

### 🛠️ Tech Stack
- **Next.js 15** (App Router)
- **Prisma ORM** with SQLite or MongoDB
- **Tailwind CSS** + **ShadCN UI**
- **NextAuth** for authentication
- **Zustand** for state management
- **API Routes** for CRUD operations

### ✨ Features
- View and manage products with stock quantity and categories
- Upload product images and detailed descriptions
- Customer dashboard: orders, messages, profile
- Admin dashboard for product and order control
- Contact & order form submission with email support
- Notification system (new orders, low stock, messages)
- Fully responsive and production-ready

---

> Built with scalability and real-world use in mind. Ideal for small-to-medium shops transitioning from paper to digital inventory and sales systems.
